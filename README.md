## r10 新增

- 工作世界由r9的1300×450擴為2600×900，寬、高各2倍，面積4倍；解除原本y=450狹帶以及normalized的舊比例限位。元件仍為原實際尺寸，沒有縮字或縮接柱來換空間。
- 非user預設場景的x／y仍按原1000×450座標基準，初始近景與r9等同清楚；首次拖曳／鍵盤移動轉成新world時保留實際位置。全覽框住現有電路，整個工作區另看完整2600×900；平移／縮放不改元件實際座標。
- world加倍時近看上限同步加倍：zoom scale最大10，仍可近看到260單位的視野寬，等同r9原先1300／5；不因world變大而降低儀表可放大程度。
- 儀表難抓的原因包含舊標題列只有30world單位高、旋轉後貼近44px接柱熱區。r10新增獨立正向「拖曳此處移動」把手，至少132×48CSS px，位在全部接柱熱區之外並繪於最上層。一般／符號模式、四角度均用同一移動入口；原表面、讀值、量程、放大表及接柱熱區保留。
- 近景旋轉、拖放完成、復原、視窗／欄位重排後，以最小鏡頭平移保持選中儀表把手可見；必要時才縮到能裝下整個元件。不為修畫面而搬動元件，真正world邊界仍會保護外框與可點區。
- 元件拖到畫布邊緣並停留可自動平移，同一手勢只存一筆可復原歷史。工具架點新增先搜尋附近空位，擁擠時使用相鄰空間並平移帶入；拖放可實際落在新world遠處，不會拉回舊1300／450界線。
- 右欄可用頂列「收合工具／展開工具」收合；全螢幕與展開按鈕始終在頂列，沒有把退出全螢幕藏掉。

每類10個、安培計／伏特計、殼底燈泡、色碼、持續燒毀／更換與左右操作沿用r9。瀏覽器觸控驗證不冒稱真機驗收。

## r9 新增

- 預設橫向工作方式：左側電路畫布，右側集中場景、顯示、播放、選中設定、元件架與編輯。控制欄獨立捲動，全螢幕按鈕固定在欄頂；畫布不因選中設定變長而縮小。
- 手機直向改為上方電路、下方獨立捲動工具，顯示可關閉的橫放提示；提示佔獨立列，不覆蓋接柱。沒有旋轉整個DOM，也不假稱可以強迫所有瀏覽器橫向。
- 全螢幕使用Fullscreen API，fullscreenchange同步進入／退出按鈕與Esc／系統退出狀態。只有使用者進入全螢幕時嘗試鎖橫向；鎖定失敗不阻擋操作。不支援或拒絕時給右欄及畫布提示，可重試或使用瀏覽器選單。
- 空間基準為r8橫向世界1000×450，r9擴成1300×450，面積由450000增至585000，增加30%。元件本體／字級不縮小，原場景保留原座標；右方新增300單位可配置空間。相機採畫布實際比例，初始全覽框住現有電路，不為空白區自動縮小。全覽框住所有現有元件與線，整個工作區則顯示完整1300×450；可放大、縮小、平移、雙指縮放。
- 新增元件會在必要時平移進視野，通常保留目前zoom；不會每次新增都縮放整場。旋轉／改向／全螢幕不重設拓撲、損壞或元件座標。
- 電池、燈泡、電阻、開關、安培計、伏特計各最多10個，包含預設與報廢未移除元件。點按、拖放、Enter／Space共用限制；滿額顯示簡短原因與aria-disabled，不顯示剩餘數量。被擋不加歷史、不改view／pending／serial。移除立即可補，更換不算新增；復原、清空與場景切換會更新可新增狀態。內建junction不計入。

安培計／伏特計用詞、殼／底燈泡、旋轉與持續燒毀機制沿用r8。獨立與作者檢查均為瀏覽器操作，非實體手機驗收。

- 中性接柱標「殼／底」，短引線清楚連到側殼與底部接點；內部仍只有兩個拓撲端子（n=殼，p=底，不代表正負），同一殼不同位置不是兩極。燈泡無正負極，反接同樣亮。

- 發光及故障火焰跟隨玻璃罩位置，數值保持正向，報廢狀態與原有更換／復原機制保留。既有6V、串並聯、旁路與故障判定不變。

## r7 新增

- D型1號乾電池外形，正端凸起、負端平面；電池上大字電壓與旋轉後文字保持正向。它是可調理想源的外形示意，6V不是單顆實體1號電池額定值。
- 選電池的單階電位圖：以黑端−為0V參考，紅端＋高出當前ΔV；相對電位不是絕對電位。手機圖面保持200×92 CSS px，低／高標籤19px、ΔV23px（橫向低高度約16／19px）。
- 電阻四色環隨5–100Ω整數滑桿精確更新：兩位數字、倍率、金色±5%；沒有隱藏四捨五入。來源：[Vishay色碼表](https://www.vishay.com/docs/20143/colorcod.pdf)。
- safety.js於既有求解器外套入持續故障狀態。安培計低阻跨源、超流、燈泡／電阻超教學額定與伏特計超量程，觸發一次短暫火焰／爆裂後留下焦黑裂痕與報廢提示。故障元件開路，實際電流0、儀表不顯示偽讀值或指針；健康並聯旁支恢復。
- 純線短接只在實際短路路徑選一條導線燒斷，並非預測實物哪一段先壞。衝突電源／不唯一支流不推定燒毀。報廢元件經改線、旋轉、換圖不復活，選中後「更換新品」；線可「更換燒斷導線」。錯線未修會再燒，復原／重設可恢復。
- 故障累計僅於動畫時鐘發生：短路0.65s、過載0.9s；暫停、拖曳／滑桿操作、待接線與開啟對話框不累計。render不新增歷史；每批真正故障只增加一次可復原快照。

以上為教學簡化：燈泡6V／1.5W、電阻5W，未建模真實內阻、保險絲或熱累積。真實儀表未必爆裂，伏特計超量程也不保證實物損壞；可能有保險絲保護等反應，參考[Fluke保險絲](https://www.fluke.com/en-us/products/accessories/fuses)。

## 直接操作

- 直接點每個開關圖示切換通斷；已移除左上全域開關與設定區的重複切換鈕。開關也能拖曳或由標籤選取。
- 選元件按「旋轉」或R，每次90度；0/90/180/270皆可操作。外觀、接柱及導線出線方向一起轉，拓撲、數值、量程、播放狀態不變。一般圖示／電路符號與裝置直橫向切換不會丟失角度。
- 旋轉維持幾何中心，只有外框／接柱真的碰到畫布邊界才平移。標籤與文字保持正向；儀表表面保持正向縮放，仍可一鍵放大讀表。已接線旋轉與移動可復原。
- 接線保留點兩端與拖端到端。拖動有預覽線與最近接柱高亮，鬆手吸附；空白、Esc或取消按鈕取消。接柱熱區保持至少44px，重疊時以距離判斷而非DOM順序。
- 點線只選取、高亮，不刪線。線旁有44px以上斷開按鈕；桌面Delete／Backspace亦可斷開，全部可復原。
- 選線後，單點端點把手可從該接柱新增分支；拖動端點才改接。無效空白落點保留原線，改接與復原均保留明確狀態。
- 拖方形轉折把手可調整走線，「重整此線」只重新整理所選線。未選線不浮到元件上方，也沒有全場剪刀模式。
- 短線中央優先選線，靠近接柱中心仍接線。端點／轉折熱區重疊時依最近可見中心判斷。選元件後的「連線」列可辨識並選取被遮住的線，只有所選線會浮顯。
- 空白拖動平移、雙指縮放、＋／−／全覽。電子以粒子呈現，傳統電流以帶桿箭頭呈現，皆可暫停與慢速。

## 走線穩定性

導線依旋轉後接柱方向向外出線，自動避開元件、不同網路長共線及轉角貼靠；交叉繪製弧形跳線。幾何相同的路徑會快取重用，選取、切圖、播放或數值變化不會讓整條線換路；移動／旋轉只重算端點改變的線，重整只清所選線的快取。其他已佔用通道會保留作避讓。

手動轉折優先遵照使用者操作，因此仍可能被拖到不理想位置；可再拖或重整。複雜密集場景不保證最佳佈局，但不會因選線就刪線。

## 模型與來源

solver.js與flow.js延續r5：理想直流電池、零阻導線／閉合開關／安培計、無限阻伏特計。燈泡為非線性穩態示意I=0.1V/√(1+|V|)，V以V、I以A；亮度與速度不是實物校準或電子真實速度。

MNA秩分析允許一致的冗餘零阻限制；安培計支流不唯一時局部標未定，動畫以一致代表解示意。短路在損壞前保護停止；損壞後故障支路開路。衝突電源仍採明示全場保護。不同幾何線交叉不自動接通。

安培計50/500/5000mA，伏特計3/15/30V，共用黑端與一紅量程端；反接、超量程、未接好／支流未定的提示在旋轉後保留。
