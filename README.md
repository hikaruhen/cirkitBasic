## r15 新增

- 將理想無限阻伏特計改為有限高阻指針式伏特計。教學靈敏度1000 Ω/V、滿刻度1 mA，3／15／30 V量程總輸入電阻為3／15／30 kΩ，按實際接入紅端決定；不是指定照片儀表的實測規格。
- MNA納入伏特計導納，回傳inputResistance及branchI。電源電流、導線KCL、其他支路讀值及負載效應隨之重算；不是額外假畫動畫。並聯吸小電流；串聯限制電流並分壓。反接讀負值、方向反轉。等電位、單端懸空、無源、開路與報廢後都零流；多紅端仍拒絕讀值。
- 伏特計粒子沿既有獨立表內通道及端帽環流動，保留三排刻度與自然旋轉。微小支流（≤1.01 mA）標記更稀疏、稍小且較慢，側欄說明「高電阻，只有微小電流」並列輸入電阻。速度採單調示意120√|I|+18|I|/(|I|+0.003) CSS px/s，不可用粒子數或速度比當作電流比；數值仍由求解決定。
- 直接跨接量程內電源為正常量測，不判短路；仍沿用超量程0.9秒簡化損壞，報廢後開路，修線再更換可恢復。
- 原理：[OpenStax 21.4 指針式伏特計串聯大電阻](https://openstax.org/books/college-physics-2e/pages/21-4-dc-voltmeters-and-ammeters)；[21.5 標準伏特計吸取小電流與負載效應](https://openstax.org/books/college-physics-2e/pages/21-5-null-measurements)。教材參數與本版教學設定分開。
- 必要測試：`node tests/voltmeter-physics-r15.cjs`、`node tests/circuit.test.cjs`、`node tests/reasonableness-r5.test.cjs`、`node tests/flow.test.cjs`、`node tests/scales-r14.cjs`、`node tests/voltmeter-flow-r15.cjs`、`node tests/meter-controls-r15.cjs`。r12／r13歷史瀏覽器測試若斷言V無穿表流，請使用保留的對應history版本；r15以有限電阻解析公式與新測試驗證。

## r13 新增

- 非零流動改為螢幕尺度的速度示意：18+90√(|I/A|) CSS px/s，慢速乘0.3；30mA約33.6px/s、300mA約67.3px/s。較大電流較快，具最低可見速度，並非真實速度或按點數定量計算電流。求解值與KCL完全不改，數值零流、開路、故障保護與無源時不移動且隱藏流動標記。

## 直接操作

- 直接點每個開關圖示切換通斷；已移除左上全域開關與設定區的重複切換鈕。開關也能拖曳或由標籤選取。
- 選元件按「旋轉」或R，每次90度；0/90/180/270皆可操作。外觀、接柱及導線出線方向一起轉，拓撲、數值、量程、播放狀態不變。一般圖示／電路符號與裝置直橫向切換不會丟失角度。
- 旋轉維持幾何中心，只有外框／接柱真的碰到畫布邊界才平移。外部讀值與操作把手保持正向；儀表表盤、刻度、單位、指針及量程字隨本體旋轉，仍可一鍵開正立的放大表。已接線旋轉與移動可復原。
- 接線保留點兩端與拖端到端。拖動有預覽線與最近接柱高亮，鬆手吸附；空白、Esc或取消按鈕取消。接柱熱區保持至少44px，重疊時以距離判斷而非DOM順序。
- 點線只選取、高亮，不刪線。線旁有44px以上斷開按鈕；桌面Delete／Backspace亦可斷開，全部可復原。
- 選線後，單點端點把手可從該接柱新增分支；拖動端點才改接。無效空白落點保留原線，改接與復原均保留明確狀態。
- 拖方形轉折把手可調整走線，「重整此線」只重新整理所選線。未選線不浮到元件上方，也沒有全場剪刀模式。
- 短線中央優先選線，靠近接柱中心仍接線。端點／轉折熱區重疊時依最近可見中心判斷。選元件後的「連線」列可辨識並選取被遮住的線，只有所選線會浮顯。
- 空白拖動平移、雙指縮放、＋／−／全覽。電子以粒子呈現，傳統電流以帶桿箭頭呈現，皆可暫停與慢速。

## 走線穩定性

導線依旋轉後接柱方向向外出線，自動避開元件、不同網路長共線及轉角貼靠；交叉繪製弧形跳線。幾何相同的路徑會快取重用，選取、切圖、播放或數值變化不會讓整條線換路；移動／旋轉只重算端點改變的線，重整只清所選線的快取。其他已佔用通道會保留作避讓。

手動轉折優先遵照使用者操作，因此仍可能被拖到不理想位置；可再拖或重整。複雜密集場景不保證最佳佈局，但不會因選線就刪線。

## 模型與來源

solver.js與flow.js延續r5：理想直流電池、零阻導線／閉合開關／安培計、無限阻伏特計。燈泡為非線性穩態示意I=0.1V/√(1+|V|)，V以V、I以A；亮度與速度不是實物校準或電子真實速度。

MNA秩分析允許一致的冗餘零阻限制；安培計支流不唯一時局部標未定，動畫以一致代表解示意。短路在損壞前保護停止；損壞後故障支路開路。衝突電源仍採明示全場保護。不同幾何線交叉不自動接通。

安培計50/500/5000mA，伏特計3/15/30V，共用黑端與一紅量程端；反接、超量程、未接好／支流未定的提示在旋轉後保留。
