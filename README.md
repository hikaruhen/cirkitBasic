## r7 新增

- D型1號乾電池外形，正端凸起、負端平面；電池上大字電壓與旋轉後文字保持正向。它是可調理想源的外形示意，6V不是單顆實體1號電池額定值。
- 選電池的單階電位圖：以黑端−為0V參考，紅端＋高出當前ΔV；相對電位不是絕對電位。手機圖面保持200×92 CSS px，低／高標籤19px、ΔV23px（橫向低高度約16／19px）。
- 電阻四色環隨5–100Ω整數滑桿精確更新：兩位數字、倍率、金色±5%；沒有隱藏四捨五入。來源：[Vishay色碼表](https://www.vishay.com/docs/20143/colorcod.pdf)。
- safety.js於既有求解器外套入持續故障狀態。電流表低阻跨源、超流、燈泡／電阻超教學額定與電壓表超量程，觸發一次短暫火焰／爆裂後留下焦黑裂痕與報廢提示。故障元件開路，實際電流0、儀表不顯示偽讀值或指針；健康並聯旁支恢復。
- 純線短接只在實際短路路徑選一條導線燒斷，並非預測實物哪一段先壞。衝突電源／不唯一支流不推定燒毀。報廢元件經改線、旋轉、換圖不復活，選中後「更換新品」；線可「更換燒斷導線」。錯線未修會再燒，復原／重設可恢復。
- 故障累計僅於動畫時鐘發生：短路0.65s、過載0.9s；暫停、拖曳／滑桿操作、待接線與開啟對話框不累計。render不新增歷史；每批真正故障只增加一次可復原快照。

以上為教學簡化：燈泡6V／1.5W、電阻5W，未建模真實內阻、保險絲或熱累積。真實儀表未必爆裂，電壓表超量程也不保證實物損壞；可能有保險絲保護等反應，參考[Fluke保險絲](https://www.fluke.com/en-us/products/accessories/fuses)。

## 直接操作

- 直接點每個開關圖示切換通斷；已移除左上全域開關與設定區的重複切換鈕。開關也能拖曳或由標籤選取。
- 選元件按「旋轉」或R，每次90度；0/90/180/270皆可操作。外觀、接柱及導線出線方向一起轉，拓撲、數值、量程、播放狀態不變。一般圖示／電路符號與裝置直橫向切換不會丟失角度。
- 旋轉維持幾何中心，只有外框／接柱真的碰到畫布邊界才平移。標籤與文字保持正向；儀表表面保持正向縮放，仍可一鍵放大讀表。已接線旋轉與移動可復原。
- 接線保留點兩端與拖端到端。拖動有預覽線與最近接柱高亮，鬆手吸附；空白、Esc或取消按鈕取消。接柱熱區保持至少44px，重疊時以距離判斷而非DOM順序。
- 點線只選取、高亮，不刪線。線旁有44px以上斷開按鈕；桌面Delete／Backspace亦可斷開，全部可復原。
- 選線後，單點端點把手可從該接柱新增分支；拖動端點才改接。無效空白落點保留原線，改接與復原均保留明確狀態。
- 拖方形轉折把手可調整走線，「重整此線」只重新整理所選線。未選線不浮到元件上方，也沒有全場剪刀模式。
- 短線中央優先選線，靠近接柱中心仍接線。端點／轉折熱區重疊時依最近可見中心判斷。選元件後的「連線」列可辨識並選取被遮住的線，只有所選線會浮顯。
- 空白拖動平移、雙指縮放、＋／−／全覽。電子以粒子呈現，傳統電流以帶桿箭頭呈現，皆可暫停與慢速。

## 走線穩定性

導線依旋轉後接柱方向向外出線，自動避開元件、不同網路長共線及轉角貼靠；交叉繪製弧形跳線。幾何相同的路徑會快取重用，選取、切圖、播放或數值變化不會讓整條線換路；移動／旋轉只重算端點改變的線，重整只清所選線的快取。其他已佔用通道會保留作避讓。

手動轉折優先遵照使用者操作，因此仍可能被拖到不理想位置；可再拖或重整。複雜密集場景不保證最佳佈局，但不會因選線就刪線。

## 模型與來源

solver.js與flow.js延續r5：理想直流電池、零阻導線／閉合開關／安培計、無限阻伏特計。燈泡為非線性穩態示意I=0.1V/√(1+|V|)，V以V、I以A；亮度與速度不是實物校準或電子真實速度。

MNA秩分析允許一致的冗餘零阻限制；電流表支流不唯一時局部標未定，動畫以一致代表解示意。短路在損壞前保護停止；損壞後故障支路開路。衝突電源仍採明示全場保護。不同幾何線交叉不自動接通。

毫安培計50/500/5000mA，伏特計3/15/30V，共用黑端與一紅量程端；反接、超量程、未接好／支流未定的提示在旋轉後保留。
